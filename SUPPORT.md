# Support

This project is in pre-release development and provides no service-level,
response-time, compatibility, or maintenance guarantee.

## Public requests

Use the repository issue forms for:

- reproducible defects that do not contain sensitive information;
- proposed capabilities or workflow improvements.

Include the smallest useful reproduction and verified environment details.
Never include credentials, tokens, private repository content, personal data,
or Prompt MCP answers.

## Private reports

Security vulnerabilities and sensitive security concerns must follow
[SECURITY.md](SECURITY.md). Conduct reports must follow
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Questions about unsupported clients, hosted accounts, or organization policy
may require help from the relevant product vendor or administrator.

  the reviewed development version and stable-only release policy.
- `scripts/lib/manifests.mjs` renders and validates canonical Codex and Claude
  sidecars, manifests, marketplaces, and the public plugin catalog.
- `scripts/lib/distribution.mjs` safely collects canonical skill sources,
  authenticates the shared engineering manual and three digest markers,
  constructs copied generated bytes, checks byte equality, and performs staged
  replacement with reverse-order rollback.

  `--check` is read-only; `--allow-incomplete` remains read-only and rejects
  partial packaging.

  validator.

## Validator Limitations

`codex-cli 0.144.3` exposes plugin add, list, marketplace, and remove commands
but no official plugin validation command, so official Codex CLI validation is
unavailable.

The optional bundled `plugin-creator` Python preflight was also run. It accepts
the Codex manifest and sidecars but rejects every shared `SKILL.md` because it
requires Claude's `disable-model-invocation` field to be absent or false. That
standalone-Codex rule conflicts with the approved coexistable bundle and
Anthropic's explicit-only requirement, so it is not used as the release gate.
The repository's closed-schema validator checks the actual combined bundle
without weakening either host policy.

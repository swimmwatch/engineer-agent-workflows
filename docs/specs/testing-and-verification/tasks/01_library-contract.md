**Strict values.** Closed DTOs reject unknown fields/kinds/operations/versions; no coercion, defaults or stripping. Before Ajv, iteratively check plain decoded JSON, own enumerable data properties, finite numbers with absolute value ≤ `9007199254740991`, safe integers where required and valid Unicode scalars. Reject cycles/getters/exotic prototypes/sparse arrays/undefined/BigInt/nonfinite numbers/negative zero. No text normalization/custom lexer. Canonical bytes: recursively key-sorted compact standard `JSON.stringify` + LF. Bounded stored reads use fatal UTF-8, standard `JSON.parse`, validation and exact canonical re-encoding equality: alternate whitespace, duplicate-key encodings and alternate number spellings fail. Decoded transport values carry no duplicate-key guarantee.

**Proposed finite budgets, not measurements.** Max decoded depth 32 (root=1), 1,000,000 visited values/properties, canonical record 16 MiB; request 1 MiB; observation 64 KiB; response 24 KiB including envelope; summary projection 8 KiB; exact-body portion ≤4096 Unicode scalars and response budget. Schema string/count bounds apply in addition, including 10,000 cases/1,000 suites, 20,000 executions, 100,000 observations/run, 32 attempts/execution, 16 updates/append batch, page limit 1–50 and cursor ≤8192 scalars. First-page application default is 25 when a later adapter explicitly constructs its DTO; missing required DTO fields still fail. Fail before effects if any limit is exceeded; never trim canonical records/denominator/history. Truncate only declared summary previews/projections, with flags/counts; reduce page rows to byte budget, never omit continuation. At most 20 redacted issues, `issues_complete=false` when sampled. Schema-only checks do not establish byte/depth/relationship/crash/native correctness.

**Identity/authority.** UUID IDs, immutable revisions and SHA-256 refs bind exact project/library/body. Rename retains ID; retirement needs provenance. Revision 1 has null parent, later revision=parent+1 with matching prior identity. IDs-only `LibrarySelector` is NOT authority. Trusted verified per-operation access is separate: no `authority_ref`, caller flag, guessed ID, cursor, readable path or ambient project grants access. Deny before protected reads/effects; redact diagnostics.

**Operations/effects.** Strict `Operation_<name>` envelopes own fields (`library`, `request_id`, `operation`, `params`, version/kind); Request unions are discovery, not extra APIs. P02/P03 list operation/result pairs. Use `Response.result` or `ErrorResponse`. Success `WriteReceipt` has `acknowledgment=acknowledged`, `effect=applied`, exact intent digest/effect kind/library/publication/saved refs, NOT proof of earlier reply delivery. Errors acknowledge a response, not save success; disclose `effect=not_applied|applied|unknown`. Lost reply means unknown until same-ID/digest `inspectOperation`, THEN exact replay/recovery; changed same-ID intent conflicts. Read status is not a write receipt. Live phase, persistence, verdict and report delivery differ; saved handles/reservations never grant live ownership.

## Technical proposal

Pure domain does no I/O or transport/store/workflow-business imports; P00 dependency direction applies. Dependency cycles may be retained as explicit case prerequisite issues rather than deleting cases; selected combined order/dependency cycles block affected executions. Ready cases require known authoritative oracle refs and actionable expectations; missing/ambiguous oracles remain draft, stale authority remains stale. Check cost provenance and automation's exact covered revisions; proposed/decided automation is not current coverage. Possible same-behavior duplicates use canonical oracle/action/input/expected/applicability identity plus explicit reconciliation provenance, never title alone; semantic near-duplicates still require caller search/review. Observations cannot rewrite definitions. Pure selection/verdict rules are P03's bound algorithm, not a second transport implementation.

**Evidence/verification.** Reuse [Ajv compilation](packages/engineer-agent-workflow-mcp/src/product/schemas.ts#L71-L129), not business imports/cache; [manifest](package.json#L8-L32) pins Node/Ajv.

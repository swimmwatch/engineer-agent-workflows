## SQLite storage contract

**Selected proposal.** Owned local directory: `library.sqlite`, rollback journal, `artifacts/`, short `write.guard`. `journal_mode=DELETE`, `synchronous=FULL`, `foreign_keys=ON`; no ATTACH/shared-cache/read-uncommitted/extensions/caller SQL. WAL improves concurrency but adds WAL/SHM/checkpoint/read-only conditions; short operations+retained publications make DELETE smaller, not measured faster/durable. BUSY is explicit. No network-FS claim, auto-migration/pruning/journal deletion or Git prerequisite.

Node 22.20: `DatabaseSync`, `prepare().get/all/iterate/run`, `exec`, `close`; options `readOnly`, `enableForeignKeyConstraints:true`, `enableDoubleQuotedStringLiterals:false`, `allowExtension:false`, `timeout:1000`, `allowUnknownNamedParameters:false`. Fixed bound SQL; close in `finally`. Synchronous busy timeout is NOT total cancellation. P01 bounds, ≤11,000 metadata/graph rows, ≤100,000 observation rows/run, 15-second cooperative batch deadline (not hard SQL interrupt). Precommit cancellation rolls back; uncertain effects require inspection. No transaction across pages/chat/run/rendering.

**Access/recovery.** Trusted root application supplies exact per-operation library authority/directory, never an ambient project/request path. Verify containment, ownership/permissions, regular DB/sidecars, and no symlink/junction/reparse escape or DB aliases; fail closed. Same-OS-user malicious processes are outside MT-036, not an excuse for accepting browser-controlled paths.

ALL reads use `readOnly:true`: absent DB fails/no-create; no DDL, repair, snapshot writes, journal-mode changes or writable fallback. Return NOT_FOUND/BUSY/RECOVERY_REQUIRED as applicable; failed recovery inspection means unknown, not absent effects. Ordinary writers exclusively create `write.guard` with operation ID/digest and process-instance nonce, then clean read-only preflight, then writable open. Every cooperating writer obeys it. Crash retains guard; reads never create/remove it. Owner removes only its exact guard after close; explicit recovery needs verified writer quiescence, never age-based/unknown-owner stealing. This prevents a cooperating crash between another writer's preflight/open.

Non-init writes require existing verified DB: hold existing `r+` handle and compare DB/directory identity before/after SQLite open; replacement fails. Node has NO documented separate writable no-create option; this is not a hostile same-user deletion-race guarantee. Only `initialize` exclusively creates a NEW owned empty area/layout v1/inventory/publication; never adopt/overwrite pre-existing content. Opens verify versions/DELETE/FK policy, not silently migrate/reconfigure.

**Atomic state.** STRICT tables: library/layout; immutable `records(kind,id,revision,digest,json)`; heads; retained `publications(sequence,digest,inventory_ref,observation_highwater)`; inventory refs; derived metadata/search/relations; immutable `observation_links(run_id,ordinal,record_ref,execution_key,attempt,publication_sequence)`; run heads; request-ID/digest receipts; artifact publication facts. Unique keys/FKs bind refs; no kind-changing IDs. Canonical bytes/digests are authority. Private SQL names flexible, responsibilities/keys binding.

Stage bounded validated candidates outside transaction. `BEGIN IMMEDIATE`: receipt FIRST; CAS publication/touched refs; graph recheck; insert records/membership/derived rows/heads/publication/receipt; response-size check; COMMIT or rollback, never stale merge. Publication digest = SHA-256 of P01 canonical `[library IDs,sequence,parent digest,inventory ref,observation highwater,saved refs,intent digest]`. Every write publishes; only definitions change inventory. Run append changes cutoff, not membership. Retain as-of publication/inventory/cutoff; no page-spanning transaction, GET materialization or automatic eviction.

**Artifact boundary.** P01 `ArtifactMetadata` binds sanitized bytes, run/source, digest/size/relative key and publication ID. Later artifact-owning operations exclusively stage files in owned operation directories, validate no escaping links and flush; short DB transaction saves staged intent; atomic rename to immutable operation destination; validate/hash then second transaction publishes ready metadata/receipt. No ready link before both exist; no DB transaction pretends to cover filesystem writes. Partial publication stays staged/unknown. Exact authorized recovery checks intent/destination/bytes and finishes only same identified publication; changed content conflicts, prior reports/unknown leftovers are not overwritten/deleted. GET verifies availability or reports unavailable, never repairs. No Allure adapter, rendering, stand provisioning or resource-claim primitive here.

Sources: [Node 22.20](https://raw.githubusercontent.com/nodejs/node/v22.20.0/doc/api/sqlite.md), [SQLite isolation](https://www.sqlite.org/isolation.html), [hot journals](https://www.sqlite.org/lockingv3.html#hot_journal). Reused current Context7 monthly-quota failure; fetched primary sources without repeating quota requests. These sources prove API semantics, not native/crash qualification.

## Technical proposal

**New workspace core.** Inside `packages/testing-workspace`, definition application/store consumes P01 domain/schema, never workflow-MCP/product business modules or skill-local storage copies. Binding `executeOperation(access,request)` takes trusted access separately from strict DTO. Exact operations/results: `open → OpenResult`, `initialize → WriteReceipt`, `queryDefinitions → PageResult`, `getDefinition → PortionResult`, `commitDefinitions → WriteReceipt`, `inspectOperation → OperationStatus`, `recoverOperation → WriteReceipt`, `repairIndex → WriteReceipt`. Unsupported run operations fail without effects until P03. Source refs remain provenance, not permission.

**Search/read.** Open checks trusted/stored IDs, never creates. AND filter categories/OR their values; empty includes retired/draft/stale. Text: ECMAScript-lowercased substring of title/purpose/action/input/expected joined by LF. Derived metadata covers every QueryParams filter; suite requirements follow member oracles, suite recent outcomes mean member results NOT coverage. Filter complete rows before bounded flagged projections; no unrelated body loads. Order `(kind,id)`; recent results by publication sequence/ordinal ≤pinned cutoff.

Pin retained publication/inventory. Cursor: version/library IDs/publication/query digest/limit/last `(kind,id)`/checksum; body cursor: publication/ref/scalar offset/prefix digest. Validate bindings/membership; NOT authority. Altered → INVALID_CURSOR; missing/incompatible → STALE_CURSOR; corrupt → CORRUPT_SOURCE, never current fallback. Later writes disclose drift only. Budget-shortened pages retain final continuation; exact get hash-checks selected canonical body/portions.

**Mutation/retry.** New revisions preserve IDs/change provenance and valid affected graph. Same ID+intent digest returns old receipt BEFORE stale CAS; changed content conflicts. Digest covers protocol/operation/library/all params, excludes only request ID. Lost reply: inspect same ID/digest FIRST. No receipt in clean quiescent state proves not_applied; inaccessible/corrupt/recovering state is unknown. Recovery takes exact original `MutationRequest` plus token over guard/intent/observed source; trusted recovery authority must establish writer quiescence. Allow writable SQLite rollback only during explicit recovery, validate versions/refs, inspect receipt; return applied evidence or replay exact unapplied intent with ORIGINAL CAS. Recovery uses a NEW request ID; atomically retains its own receipt with `reconciled_operation_id=original ID` and original effect receipt (ordinary receipts use null). Exact recovery replay checks its receipt before token/CAS; changed recovery intent conflicts. Changed state/token conflicts; unknown locks never stolen. `repairIndex` rebuilds derived navigation only, with expected source/publication/receipt, preserving canonical/history bytes. No destructive restore/migration/execution/packet advance.

**Qualification.** Future isolated DB/process checks: authority/CAS/retry/recovery, read-only/targeted reads, retained refs/final pages during appends, partial artifacts. 1000 cases/100 suites is input only. Linux+real Google Chrome evidence; others supported/unverified, no extra native gate. Test maps follow agreement.
